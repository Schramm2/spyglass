# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We want a community that is open, kind and free from harassment for all
people. Be respectful. Give constructive feedback. Accept responsibility for
your mistakes.

## Report a problem

To report behavior that does not follow this code, contact the maintainer,
[@Schramm2](https://github.com/Schramm2), privately. The maintainer reviews
each report and keeps the identity of the reporter private.

The maintainer can remove, edit or reject comments, commits, code, issues and
other contributions that do not follow this code. The maintainer can also
block a person from the project, temporarily or permanently.
