# Generated README hero and landing favicon

Both images were made with the built-in imagegen tool. The landing page was
the style reference. The hero is marketing artwork, not run evidence.
The favicon was reduced to 64 × 64 pixels for browser use.

## Hero prompt

```text
Use case: ads-marketing
Asset type: wide README hero banner for Spyglass, approximately 1600 by 640.
Primary request: Create a polished flat graphic banner that matches the attached landing page screenshot's visual system. The screenshot is a style reference only. This is a new condensed banner, not a screenshot reproduction.
Style: precise Swiss typographic design, Inter Tight style sans serif, flat square tiles with consistent 8px soot-black gutters, sharp edges, no depth.
Composition: full-bleed rectangular board. Top full-width white tile, oversized bold black wordmark "Spyglass" aligned left with generous 40px inset. Bottom board uses a large dark left tile with a two-line statement and a small lime footer tile. Right half has four equal neatly aligned grey and white tiles, each with a short tool label and a minimal simple line symbol for browser window, HTTP arrows, database cylinder and check mark. Strong alignment, ample space, exact straight baselines. Tool symbols are supporting details, typography is the hero.
Color palette: soot #0f0f0f, dark #242424, white #ffffff, pale grey #ececec and #cfcfcf, lime #dafa9c as one restrained accent tile. Black text on light fields, white text on dark.
Text (verbatim, no other words): "Spyglass"; "Verify code changes\nwith real tools."; "Keep the proof after cleanup."; "Browser"; "HTTP"; "PostgreSQL"; "Your own checks".
Constraints: one clean finished banner, readable when scaled to GitHub README width. Marketing illustration only; no invented report output or status claims. Do not copy navigation or runtime metadata from reference.
Avoid: serif lettering, engraved imagery, spyglass instrument, nautical maps, bronze, gradients, glows, shadows, rounded corners, 3D, photographs, watermarks.
```

## Favicon prompt

```text
Use case: logo-brand
Asset type: landing page favicon master, square 1024 by 1024 raster image.
Primary request: A very simple bold favicon for Spyglass, using the same flat tile design as its landing page and the previous generated hero.
Composition: a solid soot-black #0f0f0f square. Inset at center is a bold block capital S built as a continuous stepped geometric shape out of square-edged rectangular white and lime tiles. Use one white upper portion and one pale lime #dafa9c lower portion, separated only by the deliberate black channel that makes the S shape unmistakable. Huge simple mark filling roughly 75 percent of the canvas, balanced margins. Straight-on, crisp and optically balanced. Must be easily recognizable at 16 by 16 pixels.
Style: flat Swiss geometric typography, strong tile-board aesthetic, square corners.
Constraints: Exactly one isolated favicon, opaque square background, no surrounding scene, no mockup, no wordmark, no additional letters. Only black, white and lime flat colors. No shadows, gradients, glows, textures, rounded corners or 3D.
```
