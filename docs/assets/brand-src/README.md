# Brand source artwork

These are the source images and alternate candidates from the Spyglass rebrand.
Keep them so later image work can reuse the original artwork. The published
README, logo and social images remain in the parent `docs/assets/` directory;
adding these sources does not change those surfaces.

| File | Content |
| --- | --- |
| `hero-art-a.png`, `hero-art-b.png` | Alternate engraved spyglass and sea-chart compositions |
| `mark-dark-a.png`, `mark-dark-b.png` | Alternate dark-ground lens marks |
| `mark-light.png` | Light-ground lens mark |
| `run-art.png` | Browser, HTTP, database and retained-evidence illustration |
| `social-art.png` | Source artwork for a social image |

The source artwork has no text overlay. `DESIGN.md` owns the brand intent and
typography. These source files are not part of the npm package allowlist.

The editable system drawing is [`How Spyglass works.tldraw`](../../How%20Spyglass%20works.tldraw).
It describes the verification flow; it is not a substitute for the CLI help or
schemas. Before sharing an edited copy, check its saved user metadata for local
account names as well as checking the visible canvas.
