HTTP checked field by field

Expected status and JSON values, with waits for asynchronous jobs before an independent read.

GET /health200
{"status":"ok"}body
--expect-json status=okPassed

Read-only database

PostgreSQL queries run in a read-only transaction. A write is refused before it is sent. Use a restricted role: read-only mode is not a sandbox for privileged functions.

delete from jobsRefused
Spyglass accepts read-only SQL only. The query was not sent.

Source identity

Each run pins the commit and working tree. Evidence from changed source cannot pass for the original.

You judge

  • Which claims cover the request.
  • Whether a screenshot looks right.
  • What the observed behavior means.

Spyglass checks

  • The cited steps completed.
  • The artifacts exist and match their checksums.
  • The source is current and cleanup is done.

Open source. Five minutes to try.

The quickstart runs a disposable demo app with no paid services. It records a failure, a pass and a report that outlives cleanup.
